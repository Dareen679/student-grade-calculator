# Student Grade Calculator

## Project Overview

This project is a Python program that calculates and analyzes student grades.

The program stores student names and their grades in a dictionary. It calculates each student's average grade, assigns a letter grade, finds the top-performing student, calculates the overall class average, and counts how many students earned a passing grade.

## Features

This program can:

- Store student names and grades in a dictionary
- Calculate each student's average
- Assign letter grades using if, elif, and else statements
- Find the student with the highest average
- Calculate the overall class average
- Count how many students earned a C or better
- Display the results in the terminal

## How to Run the Program

Open the project folder in VS Code.

Open the terminal and run:

python3 grade_calculator.py

The student grade report will appear in the terminal.
